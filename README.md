# Тема «Кутерьма» (Quterma WordPress Theme) и плагин «Quterma Core»

Журнальная городская WordPress-тема и доменный плагин для независимого интернет-издания **«Кутерьма»** (г. Ярославль).

---

## Системные требования

- **PHP**: 7.4, 8.0, 8.1, 8.2 или 8.3
- **Обязательные расширения PHP**:
  - **`mbstring`** (Multibyte String) — **критически необходимо**. Используется для корректной обработки кириллицы (поиск, фильтры Гастрогида, нормализация тегов и категорий). Проверяется при активации плагина `Quterma Core` и темы.
  - **`json`** — для сериализации Schema.org JSON-LD и REST API.
  - **`curl`** — для фоновой синхронизации афиши с внешним API «Культура.РФ».
- **Рекомендуемые расширения PHP**:
  - **`imagick`** или **`gd`** — для генерации адаптивных WebP-миниатюр и кадрирования изображений в пропорциях 16:9, 21:10, 4:3, 3:2.
  - **`intl`** — опционально для расширенной интернационализации и ICU-форматирования (стандартное отображение русских дат и склонений работает автономно через внутренние функции темы `wp_date()` и `quterma_plural()`).

---

## Архитектурные особенности и требования

### 1. Фоновая синхронизация афиши (API «Культура.РФ»)
- Синхронизация культурных мероприятий Ярославской области выполняется **исключительно в фоне** через WP-Cron (хук `quterma_hourly_events_cron`).
- **Нулевая блокировка посетителей**: Публичные GET-запросы к `/events/` никогда не выполняют синхронных исходящих HTTP-запросов к внешним API. Если данные ещё не синхронизированы, отдаётся дружелюбный экран ожидания («Афиша обновляется»), а фоновое задание ставится в очередь.
- **Рекомендация по системному Cron**: Для стабильной и своевременной фоновой синхронизации на боевых серверах рекомендуется отключить запуск крона по хитам пользователей и настроить системный cron планировщик в crontab:
  ```bash
  # В wp-config.php:
  define('DISABLE_WP_CRON', true);

  # В crontab:
  * * * * * php /path/to/wordpress/wp-cron.php >/dev/null 2>&1
  ```
- **Статус синхронизации в админке**: В панели Customizer («Внешний вид → Настроить → Настройки темы → API «Культура.РФ»») администратор видит точную дату и время последней успешной синхронизации, количество загруженных событий и статус/текст последней ошибки (при сбоях).
- **Токены дат на чтении**: Временные токены (`today`, `tomorrow`, `week`, `month`) вычисляются динамически при чтении с учётом часового пояса сайта (`wp_timezone()`), поэтому после полуночи фильтры работают точно без необходимости немедленной пересинхронизации.

### 2. Отключение комментариев
- Функционал комментариев и pingback/trackback на сайте **полностью и намеренно отключен** на уровне темы.
- Отключение реализовано декларативно для базовых типов записей (`post`, `page`, `quterma_venue`), существующие записи в БД пакетно закрываются при активации темы.
- Тема не вмешивается в сторонние плагины форм обратной связи и не выполняет циклических проверок в `admin_init`.

### 3. «Читают сейчас» (Популярные материалы)
- **Периоды**: «Сегодня», «Вчера», «Неделя», «Месяц».
- **Ежедневные бакеты**: Просмотры ведутся в посуточных бакетах `_quterma_views_YYYYMMDD`. Благодаря этому материал 20-дневной давности, прочитанный сегодня, честно попадает во вкладку «Сегодня».
- **Асинхронный подсчёт**: Учёт просмотров выполняется через `navigator.sendBeacon` / REST-эндпоинт `POST /wp-json/quterma/v1/track-view`. Это гарантирует 100% совместимость со статическим постраничным кэшированием (Nginx FastCGI cache, WP Super Cache, LiteSpeed Cache) и исключает любые блокирующие записи в БД и cookie на публичных GET-запросах.
- **Оптимизация базы данных**: Транзиенты кэшируют только массивы ID записей (`int[]`), а сами записи загружаются единым `WP_Query` с предзагрузкой метаданных и терминов (без проблемы N+1 запросов).

### 4. Детерминированная привязка рубрик на главной странице
- Блоки главной страницы («Карусель», «Культурный слой», «Лонгриды и спецпроекты», «Кино и музыка», «Интервью») используют точную детерминированную привязку по slug/названию или через настройки в Customizer («Рубрики блоков главной»).
- Нечёткий поиск по подстрокам исключён: метка «Музыкальный фестиваль» не попадает ошибочно в блок «Кино и музыка», а рубрика «Кинотеатры» не смешивается с рецензиями.
- Карта таксономий кэшируется в памяти и transients, снижая количество запросов к БД до минимума.

### 5. SEO, JSON-LD и совместимость с SEO-плагинами
- **Типограф не ломает plain-text**: Функция `quterma_typograf` отвязана от глобальных хуков `the_title` и `the_excerpt`, исключая утечки `&nbsp;` в теги `<title>`, `alt`, `aria-label`, разметку меню и JSON-LD.
- **Корректный Schema.org JSON-LD**: Поле `publisher.logo` выводится только при наличии загруженного логотипа (исключено невалидное `logo: null`).
- **Защита от XSS / теговых инъекций**: JSON-LD сериализуется с обязательным флагом `JSON_HEX_TAG`, предотвращая разрыв тега `<script>` символами `</script>` в данных.
- **Совместимость с плагинами (Yoast, Rank Math, AIOSEO)**: При обнаружении активного SEO-плагина тема автоматически отключает генерацию собственных тегов `title`, `description`, `canonical`, `og:*` и `JSON-LD`, предотвращая дубликаты.

### 6. RSS-фиды Дзена и Рамблера (`inc/rss.php` / `quterma-core`)
- Доступны специализированные фиды:
  - `/feed/dzen/` — статьи для Яндекс Дзена;
  - `/feed/dzen-news/` — новостной поток Дзена (стандарт Яндекс.Новостей);
  - `/feed/rambler/` — новостной поток Рамблера.
- Фиды кэшируются на 5 минут в транзиентах с отдачей заголовков `ETag` и `Last-Modified` и поддержкой ответа `304 Not Modified`.
- Тег `<enclosure>` содержит обязательный атрибут `length` (размер файла в байтах).
- Текст внутри блоков `<![CDATA[ ... ]]>` защищен от последовательностей `]]>` (безопасная подстановка `]]]]><![CDATA[>`).

### 7. Разделение бизнес-логики и темы (Плагин `quterma-core`)
- Вся доменная логика вынесена в плагин **`quterma-core`**:
  - Регистрация CPT `quterma_venue` (Гастрогид) и таксономии `quterma_city`;
  - Фоновый крон и API Афиши;
  - RSS-фиды Дзена и Рамблера;
  - Аналитика и OpenGraph/JSON-LD;
  - REST-эндпоинт и суточные бакеты популярного.
- В теме оформлено исключительно визуальное представление (`single-quterma_venue.php`, шаблоны карточек, навигация, стили).
- При временном переключении на стандартную тему WordPress (например, Twenty Twenty-Four) каталог заведений, REST API, фиды и фоновые задания продолжают работать.
- Настройки контактов, аналитики и API-ключей перенесены в **Options API** (сохраняются независимо от активной темы). API-ключ сохраняется с `autoload=false` и маскируется в UI.
